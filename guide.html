機能ガイド

システム概要

このシステムは、厳選した26銘柄の日本株を毎日自動で監視し、テクニカル分析に基づく売買シグナルをLINEで通知します。自動売買ではなく、シグナル通知 + 手動発注の方式です。

  • 利確 +15%、損切り -5% の明確なルールで感情に左右されない売買判断
  • シミュレーション（仮想売買）で成績を自動追跡し、ダッシュボードで可視化

毎日の自動処理

毎日 朝8時 と 夕方18時 に以下の処理が自動で実行されます。

シグナルチェック
全26銘柄の買い/売りシグナルを検出。該当があればLINEで即時通知。
シミュレーション更新
仮想売買の成績（保有銘柄・含み損益・確定損益）を自動記録。
ダッシュボード更新
最新データでHTMLを再生成し、GitHub Pagesに自動デプロイ。
個別銘柄ページ更新
26銘柄それぞれの詳細分析ページ（チャート・条件チェック等）を再生成。
適時開示チェック
決算発表・業績修正などの重要ニュースを検出し、LINEで通知。

ダッシュボード機能

市場概況・全体指標
  • 📊市場概況バー
    日経平均・TOPIXの日次/週次変化率をヘッダーに常時表示。
  • 🗺セクターヒートマップ
    業種別の週間騰落率を色分けで表示。赤＝上昇、青＝下落で、資金の流れをひと目で把握。
  • 📈資産推移グラフ
    シミュレーション開始からの資産変動チャート。ベンチマーク（日経平均）との比較も可能。
シグナル・銘柄分析
  • 🏆買い時ランキング
    5条件の充足数で全銘柄をソート。上位の銘柄ほどシグナル発生に近い状態。
  • 🔥出来高異常検出
    20日平均の2倍以上の出来高を検知すると🔥マークで表示。大きな値動きの予兆を察知。
  • 📅決算カレンダー
    監視銘柄の次回決算日を表示。7日以内の銘柄は赤色で緊急表示。
  • 💰配当カレンダー
    配当利回りと権利確定日を一覧表示。
リスク管理・取引記録
  • ⚠ドローダウン警告
    資産がピークから -3% で黄色、-5% で赤色の警告バナーを表示。大きな損失を未然に防ぐ。
  • 📋保有銘柄一覧
    現在の含み損益、利確ライン（+15%）、損切りライン（-5%）を銘柄ごとに表示。
  • 📜取引履歴
    過去の売買記録を時系列で一覧。勝敗・損益額・保有日数を確認できる。

個別銘柄ページ（26銘柄）

各銘柄ごとに専用の分析ページがあり、現在の状態と過去のデータをまとめて確認できます。

  • 5条件チェックリスト
    各条件の達成状況と、未達成の条件については「あとどれだけで達成か」の距離を数値で表示。
  • シグナル接近度バー
    5段階のビジュアルインジケーターで、シグナル発生への近さを直感的に表現。
  • シグナル確率
    過去の同条件データからの統計的な確率を算出。どの程度シグナルに近いかを定量評価。
  • 3か月チャート
    株価 + SMA25/75 + RSI + 出来高をSVGで描画。外部ツールなしで分析が完結。
  • トレンド分析
    テクニカル指標から自動生成されるテキスト解説。現在の相場環境を文章で把握。
マルチタイムフレーム分析

日足と週足のトレンドを組み合わせて、4パターンで相場環境を判定します。

日足 上昇 / 週足 上昇
強い買い環境。トレンドが揃っており、シグナルの信頼度が高い。
日足 上昇 / 週足 下降
短期的な反発の可能性。長期トレンドに逆行しているため慎重に。
日足 下降 / 週足 上昇
押し目買いの候補。長期トレンドは健在で、短期的な調整局面。
日足 下降 / 週足 下降
見送り推奨。両方のタイムフレームが下落トレンド。

シグナル的中履歴

過去3年間に発生した全買いシグナルを追跡し、実際の結果を記録しています。

  • エントリー基準
    シグナル発生の翌営業日始値で買い付けたと仮定して損益を計算。
  • 結果の分類
    WIN 利確（+15%到達） LOSS 損切り（-5%到達） DC デッドクロスで手仕舞い OPEN 現在保有中
  • 統計指標
    勝率・平均損益率・平均保有日数をダッシュボード上段に集計表示。

LINE通知

重要なイベントが発生したとき、LINEに自動で通知が届きます。通知のタイプは以下のとおりです。

  • 買い 買いシグナル検出
    5条件すべてを満たした銘柄が見つかったとき。銘柄名・株価・条件の詳細を含む。
  • 利確損切 利確・損切りライン到達
    保有銘柄が +15% または -5% に到達したとき。
  • DC デッドクロス警告
    保有銘柄でデッドクロスが発生したとき。手仕舞いの判断材料。
  • 注目 注目銘柄（4/5条件達成）
    あと1つの条件でシグナル発生という「予備軍」銘柄を通知。事前に心構えができる。
  • 出来高 出来高異常の検知
    20日平均の2倍以上の出来高が検出されたとき。大きな値動きの前兆の可能性。
  • 開示 適時開示の通知
    決算発表・業績修正などの重要ニュースが監視銘柄に出たとき。
  • 週次 週次サマリー
    毎週土曜日に1週間のまとめを自動配信。詳細は次セクションを参照。

週次サマリー（毎週土曜 自動配信）

毎週土曜日に、その週の振り返りと来週の展望をまとめたレポートがLINEで届きます。

  • 日経平均の週間騰落率
    市場全体の方向感を確認。
  • シミュレーション成績
    週間の確定損益・含み損益の変動。
  • 保有銘柄の状況
    各銘柄の含み損益率と利確/損切りラインまでの距離。
  • 今週発生したシグナル一覧
    買い・売りシグナルの発生状況を振り返り。
  • 来週の注目銘柄
    シグナル接近銘柄（4/5条件達成など）のリストアップ。
  • セクターローテーション分析
    業種別の資金の流れ。来週有望なセクターの手がかり。
  • 今後2週間の決算予定
    監視銘柄の決算日が近い場合に表示。決算前後の値動きに備える。

メンテナンス情報

基本的には自動で動き続けますが、外部サービスの変更などにより、まれに手動対応が必要になる場合があります。

対象頻度の目安内容
yfinance 年1-2回 Yahoo Finance APIの仕様変更に伴い、ライブラリ更新が必要になる場合がある。
kabutan.jp 不定期 HTML構造の変更時に tdnet_monitor.py のスクレイピング部分を修正。
Python / ライブラリ 年1回程度 依存パッケージのアップデート推奨。pip install -U -r requirements.txt
監視銘柄の入替 任意 config.json を編集して銘柄を追加・削除可能。
自動ヘルスチェック 常時 エラー発生時にLINE通知で検知可能（healthcheck.py）。通知が来たら対応する。
このガイドはシステムの現在の機能をまとめたものです。機能追加や変更はClaude Codeで随時対応できます。
